# Фінальний проєкт з реляційних баз даних
У роботі виконано роботу з датасетом щодо інфекційних захворювань у MySQL Workbench.

## Виконані завдання
1. Створено схему pandemic та імпортовано таблицю infectious_cases
2. Перевірено кількість завантажених даних - 7271 рядок.
3. Використано нормалізацію даних:
- створено таблицю entities для зберігання унікальних значень Entity та Code;
- створено таблицю infectious_cases-normalized;
- таблиці повязано за допомогою зовнішнього ключа entity_id;
- після пернесення даних перевірено кількість записів - 7271 рядок.
4. Для поля Number_rabies виконано групування даних за країнами та розраховано:
- середнє значення (avg);
- мінімальне значення (min);
- максимальне значення (max);
- суму (sum).
Результат відсортовано за середнім значенням у порядку спадання та обмежено до 10 записів.
5. Виконано роботу з датами:
- значення Year перетворено на дату першого січня відповідного року;
- отримано поточну дату за допомогою curdate();
- за допомогою timestampdiff() визначено різницю між датами у роках.
6. Створено користувацьку ф-ю year_difference(), яка приймає рік і повертає різницю в роках
між першим січня заданого року і поточною датою.
Основні використані SQL-можливості
у роботі використано:
- create database, create table
- insert into... select
- join, foreign key
- group by, order by
- avg(), min(), max()
- cast
- str_to_date(), concat()
- curdate(), timestampdiff()
- користувацькі функції

## Результат
Усф єтапи фінального проєкту виконано. Дані імпортовано, нормалізовано та перевірено SQL-запитами. 
Проведено статичний аналіз даних, виконано роботу з датами та створено користуацьку SQL-ф-ю.
Результати виконання завдань наведено на скріншотах у репозиторії.
